Field-research quality test: ran the same topic (Christian theology and AI -- imago Dei, personhood, pastoral care automation) through ChatGPT, Gemini, Perplexity, and Watson's own field_research skill (jobs/research/field_research.py), to compare source quality and verbatim-quote fidelity.

Findings:
- All three external agents independently found the Vatican's Antiqua et nova (Jan 2025) as a top source; Watson's unmodified skill did not, because it has no path to denominational/magisterial statement pages (general web search + arXiv/Semantic Scholar/OpenAlex/CrossRef only).
- Watson's skill also lost real candidates to 403s (ResearchGate mirror of the Hermanto imago Dei paper, a Taylor & Francis mirror of Stoddart's pastoral-care paper) that the browsing-capable external agents routed around via alternate mirrors.
- Spot-checked the three external agents' Antiqua et nova quotes against the live Vatican document directly. ChatGPT and Perplexity both confirmed verbatim. Gemini's quote had a fabricated tail clause appended to a real sentence -- despite being labeled UNVERIFIED like the others. This is the exact failure mode Watson's skill is coded to prevent (a quote must literally appear in the fetched page text or it is dropped).

Fixes made to jobs/research/field_research.py as a direct result:
1. Added a denominational/magisterial site search (_DENOMINATIONAL_SITES: vatican.va, erlc.com, sbc.net, umc.org, oca.org, nae.org, cslewisinstitute.org, episcopalchurch.org) run alongside the general web search.
2. Added an Unpaywall fallback (new module jobs/research/unpaywall.py) -- when an OpenAlex/CrossRef lead carries a DOI and its publisher landing page returns too little text (paywall/403), look up a legal open-access mirror by DOI and retry the fetch there before dropping the candidate.
3. Added config/settings.py:RESEARCH_CONTACT_EMAIL for Unpaywall's courtesy-identification requirement.

Verified the upgraded skill still runs end to end (venv/bin/python3, not system python -- system python was missing the anthropic/arxiv packages the skill depends on, a separate pre-existing issue worth knowing about but out of scope for this fix).

Attached: the merged, tier-labeled research file (guardrails-ai-theology-field-research.md) for the actual book-usable content -- sources deduped across all four runs, disagreements and unverifiable quotes flagged per the project's Field Research Protocol.
