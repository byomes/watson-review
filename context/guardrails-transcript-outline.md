**Thesis — REPLACED 2026-09-23. Use the new version; the old one is retired.**

NEW locked thesis (2026-09-23, [#1712]), verbatim:

**Note — placement decision:** the "two-AI-engines" 300-billion-to-one Messianic-prophecy probability story (built then entirely discarded once Bill recognized it rested on unknowable inputs) illustrates this chapter's territory but was explicitly assigned to **Ch.7** instead, by Bill's direct choice ("I like 7 better") [#1703]. See Ch.7 below for the full story. Don't duplicate it here.

**Explanation chain (revised and locked 2026-09-17, [#1707]):** Token prediction — "guessing, not talking" — as the **opening frame** (AI doesn't think or speak, it probabilistically predicts the next most likely token), followed by the five-step technical chain:
1. Human enters a prompt
2. Language model reads/processes the language
3. Intent detection
4. Skill evaluation (added as its own distinct step 2026-09-17 — does the model actually have a tool/skill matching the detected intent)
5. Tool execution

Token prediction sits underneath the whole chain, not as a sixth link — Bill was explicit about this ordering.

**Lay explanation example:** Genesis 1:1 tokenized ("In [the] [begin][ning] [God] [creat][ed]...") to show a token as a "chunk of letters" — sometimes a whole word, sometimes a root the model predicts an ending for (create/created/creating/creates), which the machine does purely by probability, not grammatical understanding [#1705].
